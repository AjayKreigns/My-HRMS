## Page speed on a phone-class device

Phone profile: 375 px wide, 4x CPU slowdown, 1.6 Mbps and 150 ms latency, cache off, median of 3.

| Page | First paint (2026-11-27 / this morning / now) | Largest paint (2026-11-27 / this morning / now) | Blocked time (2026-11-27 / this morning / now) | Transferred (before / now) |
|---|---|---|---|---|
| Login | 2156 / 2104 / 1676 ms | 2500 / 2448 / 2028 ms | 336 / 313 / 386 ms | 535 / 263 KB |
| Home | 2584 / 2428 / 1652 ms | 2584 / 2428 / 1652 ms | 928 / 788 / 548 ms | 274 / 174 KB |
| Payroll analytics | 2652 / 2616 / 1688 ms | 3460 / 3500 / 3732 ms | 1005 / 1077 / 734 ms | 447 / 450 KB |

Desktop is unchanged and fast (first paint 0.19 to 0.25 s).

Measurement noise: first paint repeats within about 20 ms between runs; blocked time varies by roughly 70 to 100 ms (the login page ranged 331 to 465 ms in this session with identical code), so small blocked-time differences are not meaningful.

What changed:
1. **Pages load on demand** (`React.lazy`). The main script went from 648 kB to 300 kB (198 to 99 kB compressed). Login and Inbox stay in it; every other page, and Payroll and the admin tools (225 kB), load when first opened.
2. **Login photo** from a 254 KB JPEG to an 85 KB WebP at quality 70 (visually identical in a side-by-side check). Login drops from 535 to 263 KB.
3. **Idle prefetch.** Four seconds after the first page is up, the other pages' code is fetched one piece at a time while the browser is idle (admin tools only for admins). First visit to a page, after 9 s idle, on the phone profile:

| Page | Without prefetch | With prefetch |
|---|---|---|
| Leave | 483 ms | 297 ms |
| Finances | 272 ms | 78 ms |
| Payroll | 817 ms | 197 ms |
| Admin pages | 126 ms | 133 ms |

Tried and reverted: **preloading the four common fonts** made first paint about 200 ms slower on all three pages (the extra 48 KB competes with the main script on a slow connection), so it was removed.

Not fixed:
- **Payroll opened directly** (a refresh on that page): largest paint 3.5 s before, 3.7 s now. The page needs the main script, then the admin code (64 KB compressed plus six shared page bundles), then renders a heavy page; the Archivo fonts add 173 KB after that. Reaching 2.5 s would need smaller admin code or fonts.
- **Blocked time** is 0.39 to 0.73 s against a target of 0.3 s; React itself is about 140 KB of the 385 KB of source in the main script, so it is close to its floor.
- Leave page animation (1.3 s of updates) is unchanged.

Ratings (Google's guidance): first paint good at 1.8 s or less (met on all pages); largest paint good at 2.5 s or less (met on Login and Home, not Payroll); blocked time good at 0.2 s or less and poor above 0.6 s (Home 0.55 s needs improvement, Payroll 0.73 s poor).
